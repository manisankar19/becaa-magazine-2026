# BECAA Maharashtra Magazine 2026 Website Prototype

Version 0 is a local, three-item static website prototype. It does not import the full magazine and is not deployed publicly.

## Commands

```powershell
npm.cmd install
npm.cmd run inventory
npm.cmd run import
npm.cmd run normalize
npm.cmd run validate
npm.cmd run build
npm.cmd run test
npm.cmd run qa
npm.cmd run release:v0
```

Use `npm.cmd run serve` to view locally at `http://localhost:8086/`.

## Scope

The prototype includes exactly:

- one office-bearer message
- one ordinary article or event report
- one reliably matched advertisement, or a labelled non-release placeholder if no reliable match exists

Original files in `01_REFERENCE_2025`, `02_INCOMING_CONTENT`, `03_ADVERTISEMENTS`, and source workbooks/documents in `04_MAGAZINE_WORKING` are not modified.

## Current state (Sprint v3, September 2026)

The commands above are the original Version 0 sequence. The publication has since grown through V1 and V2 (see `../CHANGELOG.md` and `../sprints/`), and Sprint v3 adds a registration gate and an administrator dashboard. The magazine itself is still generated by Eleventy from `src/_data/publication.yaml` and the Markdown under `src/content/`.

### Prerequisites (all environments)

- Node 22 LTS; `npm install`.
- Playwright's Chromium for tests and QA: `npx playwright install chromium` (not installed by `npm install`).
- PostgreSQL 16 client/server binaries for the application tests: `npm run db:local:start` creates a loopback-only cluster in `.pgdata/` (git-ignored) with `becaa_dev` and `becaa_test` on port 5433.
- Copy `.env.example` to `.env.local` and fill it in for local work. `.env.local` is git-ignored and must never be committed.

### Everyday commands

```sh
npm run tracker:validate && npm run validate   # tracker + manifest gates
npm run build && npm run test && npm run qa    # site, smoke tests, screenshots
npm run pdf && npm run qa:pdf && npm run qa:ad-backgrounds
npm run test:unit && npm run test:integration  # integration needs the local PostgreSQL
npm run typecheck && npm run check:secrets && npm run check:sql
```

## Registration application

Visitors register once (name, email, category and a few category-specific fields) before the magazine opens; the details are stored in PostgreSQL and a single administrator can see statistics, search registrations and download a CSV. Design and decisions: `../sprints/v3/PRD.md` §5; threat checks: `../sprints/v3/THREAT_CHECKS.md`; deployment and rollback: `DEPLOYMENT.md`.

| Piece | Location |
|---|---|
| Public landing page with privacy notice and form | `src/welcome.njk`, `src/assets/js/welcome.js` |
| Gate (no session → `/welcome/`; assets/PDF → 403) | `middleware.ts` (Vercel), `lib/gate.ts` (shared with the local server) |
| API handlers (Web `Request`/`Response`) | `api/register.ts`, `api/health.ts`, `api/admin/*.ts` |
| Validation, sessions, CSRF, hashing, rate limits, CSV | `lib/*.ts` |
| Schema and migrations | `db/migrations/`, `db/rollback/`; `npm run db:migrate`, `db:status`, `db:rollback -- <n>`, `db:purge` |
| Administrator dashboard | `src/admin.njk`, `src/assets/js/admin.js` |
| Local server mirroring Vercel | `npm run dev:app` → http://127.0.0.1:8087 |
| Administrator password hash | `npm run admin:hash` (masked prompt; paste the hash into Vercel, never into a file) |
| Live-browser end-to-end suite | `npm run e2e:app` (add `-- --base-url <preview>` for a deployed preview) |

Editorial lists (departments, batch-year floor, privacy-notice version and retention date) live in `src/_data/registration.json`, read by both the templates and `lib/config.ts`.
